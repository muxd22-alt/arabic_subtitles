سطر واحد في تيرمكس

افتح تطبيق تيرمكس ونفّذ هذا الأمر لمرة واحدة. يقوم بتثبيت الحزم (git, nodejs, ffmpeg)، تنزيل محرك الترجمة الجاهز (‏16MB، بدون أي بناء على الهاتف)، وتنزيل النموذجين معاً (~1.2 جيجابايت — ترجمة + صوت) بأمان واستئناف تلقائي.

pkg install -y curl; curl -fsSL -o ArabicSubs.sh https://raw.githubusercontent.com/muxd22-alt/arabic_subtitles/main/ArabicSubs.sh; bash ArabicSubs.sh

استخراج الصوت الذكي

إذا لم يتوفر أي ملف ترجمة، يستخرج الصوت عبر ffmpeg ويُفك عبر whisper.cpp ثم يُترجم بسلاسة.

bolt

دفعات ترجمة متوازية

تقسيم الأسطر على 4 مسارات متوازية للترجمة مع معالجة ذكية لتداخل المقاطع الصوتية ومنع التكرار.

queue

نمط قائمة الانتظار (Queue)

معالجة الأفلام تباعاً لتجنب حرارة المعالج، مع إمكانية تحديد فيلم معين أو استبعاد أفلام محددة بسهولة.

cleaning_services

تنظيف وفحص وإعادة تشغيل

زر واحد داخل التطبيق لإعادة تنظيف حالات التخطي، مطابقة ملفات .ArabicSubs.ar.srt المنتهية، والانطلاق.

insights

لوحة مراقبة حية

تتبّع لحظي للترجمة الحالية، عدد الأسطر المكتملة، وحالة الخادم عبر واجهة محلية خفيفة وسريعة.

ترتيب فحص المصادر الذكي

يتوقّف المحرك عند أول مصدر صالح ومتاح — ويسجّل كل قرار في logs/decisions.jsonl.

check_circle 1. الملف المترجم موجود مسبقاً (.ArabicSubs.ar.srt) ← تخطٍّ فوري لتوفير الوقت
branding_watermark 2. ترجمة عربية جاهزة بجانب الفيديو (.ar.srt) ← وضع العلامة المائية والحفظ
translate 3. ترجمة إنجليزية بجانب الفيديو (.en.srt) ← تجزئتها وترجمتها عبر Hy-MT2
video_library 4. مسار ترجمة مدمج داخل الحاوية (MKV / MP4) ← استخراجه ثم ترجمته
graphic_eq 5. لا توجد ترجمة ← تقطيع الصوت لمقاطع 5 دقائق ← تفريغ whisper ← ترجمة
skip_next 6. لا يوجد صوت ولا ترجمة ← تسجيل التشخيص والتخطي بأمان
