اختر المجلدات

حدّد مجلدات الأفلام والمسلسلات من خلال تطبيق المرافق أو مباشرة من تيرمكس.

🧠

ترجمة محلية

نموذج Hy-MT2 بحجم 440 ميجابايت يعمل داخل llama-server على معالج/معالج رسومي هاتفك.

🎙️

من الصوت إلى النص

الفيديوهات بلا ترجمة تُقطَّع إلى مقاطع متوازية وتُفكَّ عبر whisper.cpp ثم تُترجَم.

⚡

معالجة متوازية

مقاطع الترجمة تُرسل على 4 مسارات بالتوازي، ومقاطع الصوت تُستخرج بالتوازي أيضاً.

📁

ملف جاهز بجانب الفيديو

النتيجة Movie.ArabicSubs.ar.srt مع علامة مائية — لا يمسّ الفيديو نفسه.

📊

سجل قرارات

كل قرار (ترجمة، تخطي، سبب الفشل) يُسجَّل في logs/decisions.jsonl.

ترتيب المصادر

١. المخرج موجود مسبقاً ← تخطٍّ
٢. ترجمة عربية جاهزة ← لصق العلامة المائية
٣. ترجمة إنجليزية ← ترجمة عبر Hy-MT2
٤. مسار ترجمة مضمّن ← ترجمة عبر Hy-MT2
٥. لا شيء ← استخراج الصوت ← whisper.cpp ← ترجمة
٦. لا صوت ولا ترجمة ← تسجيل السبب والتخطي

التثبيت على تيرمكس

termux-setup-storage
pkg update && pkg install nodejs ffmpeg -y
git clone https://github.com/muxd22-alt/arabic_subtitles.git
cd arabic_subtitles && npm install
bash scripts/setup-termux.sh
node bin/arabic-subs.js run --media /sdcard/Movies

ملاحظة: ثبّت تيرمكس من F-Droid وليس من متجر Google Play.
