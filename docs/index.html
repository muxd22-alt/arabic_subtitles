ماذا يفعل؟

خط أنابيب واحد يختار المصدر المناسب لكل فيديو تلقائياً، ويسجّل سبب كل قرار.

📂

اختر مجلداتك

أضف مجلدات الأفلام والمسلسلات من التطبيق، ويتعرّف المحرك على كل ملف فيديو وترجماته تلقائياً.

🧠

ترجمة محلية بـ Hy-MT2

نموذج ترجمة بحجم ~440MB يعمل داخل llama-server على معالج هاتفك — لا سحابة ولا إنترنت.

🎙️

من الصوت إلى نص

الفيديو بلا ترجمة؟ يُقطَّع الصوت إلى مقاطع متوازية، يُفكّ عبر whisper.cpp، ثم يُترجَم.

⚡

معالجة متوازية

دفعات ترجمة على 4 مسارات بالتوازي واستخراج صوت متوازي، مع إعادة محاولة تلقائية للدفعات الفاشلة.

🧭

دليل خطوة بخطوة

التطبيق يمشي معك سطراً بسطر داخل تيرمكس: نسخ تلقائي للأوامر، وتشغيل مباشر بضغطة واحدة، ويتجاهل ما تم إنجازه مسبقاً.

📊

حالة مباشرة

تتبّع المحرك لحظياً داخل التطبيق: الملف الحالي، عدد الترجمات، وأي فشل — عبر واجهة محلية.

ترتيب المصادر لكل فيديو

يتوقّف عند أول مصدر متاح — وكل قرار يُسجَّل في logs/decisions.jsonl.

الملف موجود مسبقاً ← تخطٍّ (عدم التكرار)
ترجمة عربية جاهزة بجانب الفيديو ← لصق العلامة المائية
ترجمة إنجليزية ← ترجمتها بالكامل عبر Hy-MT2
ترجمة مضمّنة داخل الملف ← استخراجها ثم ترجمتها
لا شيء ← استخراج الصوت ← whisper ← ترجمة
لا صوت ولا ترجمة ← تسجيل السبب والتخطي

التثبيت في تيرمكس

افتح التطبيق: أمر واحد في تيرمكس ينفّذ كل شيء، ثم تختار مجلداتك داخل التطبيق.

install 
# 1. أمر واحد: الإذن + الحزم + الكود + llama-server + whisper (آمن لإعادة التشغيل)
$ pkg update -y; pkg install -y git nodejs ffmpeg; git clone https://github.com/muxd22-alt/arabic_subtitles.git ~/arabic_subtitles 2>/dev/null; cd ~/arabic_subtitles; git pull --ff-only 2>/dev/null; npm install; ARABIC_SUBS_SKIP_UPDATE=1 bash scripts/setup-termux.sh

# 2. التشغيل — يسأل قبل تنزيل النماذج (~590MB)
$ node bin/arabic-subs.js run --media /sdcard/Movies --media "/sdcard/TV Shows"
[Engine]   Hy-MT2-1.8B (1.25-bit GGUF)  440 MB  huggingface.co/tencent/Hy-MT2-1.8B-1.25Bit-GGUF
