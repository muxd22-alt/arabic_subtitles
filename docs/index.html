اختر مجلد الوسائط

استخراج الصوت الذكي

إذا لم يتوفر أي ملف ترجمة، يستخرج الصوت عبر ffmpeg ويُفك عبر whisper.cpp ثم يُترجم بسلاسة.

bolt

دفعات ترجمة متوازية

رقم واحد في الإعدادات («توازي الترجمة») يضبط النسخ الصوتي والترجمة معاً: من ١ حتى عدد أنوية جهازك (بحد أقصى ٨). رقم أعلى = ترجمة أسرع وجهاز أسخن.

queue

نمط قائمة الانتظار (Queue)

معالجة الأفلام تباعاً لتجنب حرارة المعالج، مع إمكانية تحديد فيلم معين أو استبعاد أفلام محددة بسهولة.

terminal

سجل المحرك داخل التطبيق

نافذة طرفية قابلة للفتح تعرض تقدم المحرك والأخطاء مباشرة — دون حاسوب ودون تيرمكس.

cleaning_services

تنظيف وفحص وإعادة تشغيل

زر واحد داخل التطبيق لإعادة تنظيف حالات التخطي، مطابقة ملفات .ArabicSubs.ar.ass المنتهية، والانطلاق.

insights

لوحة مراقبة حية

تتبّع لحظي للترجمة الحالية، عدد الأسطر المكتملة، وحالة المحرك مباشرةً من خدمة الواجهة الأمامية داخل التطبيق — دون خادم محلي.
